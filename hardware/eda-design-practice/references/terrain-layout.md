# 地形布局：质量 → 峰谷 → 展平

## 目标不是「少交叉」

> 「如果网络很复杂，交叉是不可避免的，这是由于网络的原生性造成的，任何算法都解决不了。
>   我的重点是**自然**——如果两个山峰把中间的一个元件拉紧，它的方向会自然正确。」
> —— 用户 2026-09-29

**这句话推翻的是目标函数，不是细节。** 之前把交叉数当优化目标是错的：

| | 地位 |
|---|---|
| 网表正确 | 硬闸门 |
| 几何（穿本体/压符号） | 硬闸门 |
| **总张力 E / 连接数** | **主判据**——平衡态就是 E 最小，这个数就是「自然程度」 |
| 交叉数 | **观测量**，只报告，不做闸门 |
| 人眼 | 最终判据 |

## 模型：每个元件只有**一个**核心参数

```
质量 m_i = 接入信号网的引脚数          ← 拓扑量，不是尺寸量
边权 w   = 1/(k−1)，k = 该网节点数     ← 一条网的总拉力恒定
高度场   min Σ m_i(h_i−m̂_i)² + λ Σ w_ij(h_i−h_j)²
```

三句话逐条对应：**重的钉在自己高度**（第一项权重大）、**轻的自然垂落**
（高度≈邻居加权平均）、**被另一边更大的峰拉起来**（平均值自动抬升）。

★ **峰是局部极大，是解出来的，不是人钉的。** 这是它和「手工指定 hub」的根本区别。
  稀疏正定系统，Jacobi 迭代，**无随机、可复现**。

⚠ `gravity.py`（PCB 侧）写着「质量恒为 1，不按面积配质量」——它拒绝的是
  **按器件尺寸**配质量（有道理），但连带把**按引脚数**也放弃了。
  引脚数是拓扑量，不违反那条原则，是把它补完整。

### 分水岭切盆地

沿最陡上升走到峰。**实测有效**：daikin-rcu P4 自动切出了「负载开关块」
（Q2/Q3/R42/R43），没有给它任何领域知识。

⚠ **孤岛会产生伪峰**：一条全是 m=1 的链高度场是平的，「局部极大」会随便挑几个。
  判据：盆地内最大质量 == 1 → 当孤岛单独停泊，别硬塞进主图。

## 展平 = 地图投影，必须选择牺牲什么

半球无法无畸变展平（高斯绝妙定理）。

| 投影 | 保住 | 牺牲 | 在原理图里的后果 |
|---|---|---|---|
| 保角 | 局部角度 | 面积 | 密集山谷被压扁 → 器件重叠 |
| 等积 | 面积 | 角度 | 辐条角序乱 → 交叉暴增 |
| **方位等距** | **到峰心距离 + 角序** | 周向长度 | 外圈弧长被拉长 |

**选方位等距**，因为它的畸变方向**正是需要的**：周长随 r 线性增长，
而层级越低的环上器件越多。畸变自动给外圈腾了周长；保角投影反而会把外圈压回去。

```
θ ← 所连峰引脚的角     r ← 高度落差 Δh
```

## ★ 接缝要**剪开**，不要拉伸 —— 用端口

> 「对于特别复杂的，比如两个质量大的元件，其实可以分拆，这是你说的接缝不可避免。
>   即使在一个 sheet 中，也可以把它们拆成 2 个 block，中间用端口连接。」
> —— 用户 2026-09-29

**这是图集模型的最后一块。** 多个峰 → 多张图 → 必有接缝，畸变总要有地方去。
在接缝处「剪开、两边各放一个端口」比「拉一根长线跨过去」自然得多，
人分块画图本来就是这么做的。

→ 实现：跨盆地的网 `label_kind` 直接返回 `port`，不画跨接缝的长线。

## 实现上踩到的坑

### 1. 不变量是**角序**，不是角度值

我第一版写成「消除重叠时绝不改角度、只沿半径推」—— 过严，而且**会死锁**：
**同高度的器件落在同一半径上**（P4 的 Q5/Q6 都是 h=0.51），不许动角度就只能靠半径推，
而把图缩回纸内的 `fit` 又把推开的量全部抵消 —— 两步互相抵消，
结果器件本体重叠、导线穿本体 5 处、网表断 5 条。

→ 正确：**允许保序撑开角度**（剪环→展直线→按序最小间隔投影→合环），只是不许交换次序。

### 2. 按比例缩放之后**必须回栅格**

`fit` 缩放产生 877 / 1051 这种坐标，下游的栅格微调每轮 +5 永远对不齐 →
中止 → **整页连线全没**。

### 3. 姿态：不要解力矩，**枚举**

原理图符号轴对齐，姿态空间只有 4 旋转 × 2 镜像。力矩是连续量、是代价函数的梯度；
**定义域只有 8 个点时直接全算就是精确解**，更便宜、无随机、可复现。

⚠ 两脚件的 8 种姿态会**退化**（实测：竖放电阻 rot=90 mirror=True/False 引脚完全重合）。
  枚举前按「产生的引脚映射」去重，否则会在等价姿态里随机选，结果不可复现。

⚠ 「不许从引脚背面出线」**不是独立的美学规则**，它是**长度的估计**：
  背对目标时导线要绕过本体，真实布线更长。这样整个系统才只有一个能量。

## ★ 展平必须是**一次带约束的优化**，不是三步贪心

第一版是「投影 → 保序撑开 → 缩放回纸内」三步各做各的 —— 它们优化的是三个
不同的东西，**互相抵消**。改成单一目标 + 硬约束的坐标下降：

```
目标  min E（总张力）              ← 唯一目标
约束  ① 占位互不重叠 ② 在图框内 ③ 落栅格
做法  按质量降序遍历，每个器件试「8 方向 × 3 步长」和「8 种姿态」，
      只接受让 E 变小**且不违反约束**的动作
性质  单调下降 → 必然终止；无随机、按质量定序 → 可复现
```

⚠ **角序不要当硬约束。** 投影结果当初值，角序已嵌在里面；破坏角序会让导线变长、
E 上升，所以 E 自己会守住它。硬锁角序反而把可行域切碎（就是坑 1 的死锁）。

实测 P4：E/连接 **245 → 47.5**（降 81%）。

## ⚠⚠ 但它交不了货：优化器和布线器各说各话

**这是这一轮最重要的负面结果。**

E 降了 81%，可四页里 P4 反复卡在网表验收：

```
Q3_BASE 连线 (870,530)→(870,530)      ← 两个器件的**引脚落在同一坐标**
VBUS/USB_DM/CTS_N 一簇 … 找不到能放符号的支线位
CC1_N 实际 ['J2.A5','U4.2']           ← 不同网被连到了一起
```

三层原因，一层比一层根本：

1. **占位盒只算本体，没算引脚。** 引脚伸在本体之外 → 本体不重叠、引脚却重合
   → 零长度导线 `create failed!`。→ 占位盒必须是 **本体 ∪ 全部引脚接线点**。
2. **「不许碰」不等于「线能过」。** 只最小化 E 会把器件挤到刚好不碰
   （弹簧的极小值是所有点重合），然后路由一条干净路径都找不到。
   → 净空要按**走线走廊**取（一条支线 30 + 余量，本工程取 60），不是按「不碰」取。
3. **根本原因：布局优化器不知道布线器需要什么。** 它只知道「器件别叠」，
   不知道**每个引脚要有出线通道、每个网络符号要有落位**。
   → 这和布线阶段学到的「第零遍预留符号位」是同一课，只是升到了布局层：
     **占位模型必须包含下游会用到的空间**，否则上游的最优就是下游的死局。

→ 修到第 2 层之后错网从 8 条降到 4 条，**仍未通过**。第 3 层没做完。

## 第三层：布局和布线必须用**同一套空间账本**

前两版的占位只有「本体」和「本体+引脚点」，而**布线器需要的空间它一概不知道**。
于是布局优化器给出的最优，正是布线器的死局 —— **E 越小越交不了货**。

占位模型改成：

```
占位 = 本体 ∪ 每个引脚的**出线走廊**（长 45）
          ∪ 需要符号的引脚的**符号位**（长 100 = 支线 30 + 符号 60 + 余量）

重叠规则：本体 vs 任何   → 不许碰（留 SEP 走廊余量）
          走廊 vs 走廊   → **同网允许重叠**（它们本来就要连一起），异网不许
          符号位          → **一律独占**，连同网也不许
```

最后那条是实测撞出来的：符号位如果对同网开放，`U4.4` 的 `RTS_N` 符号位会被
同网的 `Q5`/`Q6` 走廊占掉，布线阶段「找不到能放符号的支线位」，整条网断。
**导线可以共用通道，符号不能共用位置。**

「需要符号的网」= 电源地 ∪ 跨页端口 ∪ **跨盆地**的网。
→ 布局阶段就要知道哪些网将来要挂符号，这也是「同一套账本」的一部分。

**效果**：P4 的失败网 **8 → 4 → 1**。

## ★ 不要把一切编码成硬约束 —— 挤了再外扩才是正解

> 「你不必死规则、一定要按公式映射坐标，有重叠就算失败。半球映射到平面一定会有挤压、
>   可能重叠，这很难避免。但原理图并不是所有平面都是满的，甚至很多空白，
>   再挤一挤外扩可能才是正解。」 —— 用户 2026-09-29

**这条纠正的是方法论。** 我把走廊、符号位全做成降能量时的硬约束，结果优化器被捆死：
E 从 47.5 退到 130.5，而且满盘冲突无解。

**实测占用率只有 17%（P2 12%）—— 图纸空得很，问题从来不是「放不下」。**

正确分工：

```
① 降能量：目标 min E，只挡**本体互叠**（防止弹簧塌成一点）
② 外扩  ：后处理，把占位冲突的器件推进空白处
```

### 外扩的三次失败，每次都是方向错了

| 版本 | 做法 | 结果 |
|---|---|---|
| 1 | 沿**径向**（远离重心）推一步 | 60 轮一个冲突都解不掉 —— 径向不是「分离这一对」的方向 |
| 2 | 按**最小平移向量**逐对推 + 严格单调 | 11 → 9 就卡死 —— 有些冲突要「先变差再变好」 |
| 3 | **同时松弛**：每个器件按所受全部 MTV 之和一起动 | 11 → **4**，四页全部通过网表 ✓ |

### 预留必须按「器件 × 网」，不是按引脚

J2 是 16 脚 Type-C，**6 个 GND 脚**如果各留一块 100 长的独占符号位，
就多留了 6 倍 —— 实测 44/61 的冲突来自这里。
而布线时它们会就近串成一簇、**共用一个符号**（R2）。
→ 同一器件上同一个网只留**一个**符号位（取最外侧那个脚）。

### 冲突规则要按**种类**分，不能一刀切

| | 规则 | 理由 |
|---|---|---|
| 本体 vs 任何 | 一律冲突 | 器件不能叠 |
| 符号位 vs 任何 | 一律冲突 | 符号是图形，必须独占 |
| 走廊 vs 走廊，同网 | 不冲突 | 本来就要连一起 |
| 走廊 vs 走廊，异网**垂直** | **不冲突** | X 形穿越不连接 |
| 走廊 vs 走廊，异网**平行重叠** | 冲突 | 共线会被合并 = 短路 |

倒数第二条漏掉时，等于要求所有出线通道互不交叉 —— 那不可能满足。

四页全部改用地形布局，**网表全绿**（80 器件 / 55 网络 / 单节点 0 / 规格逐条对上）：

| | P1 | P2 | P3 | P4 |
|---|---|---|---|---|
| 交叉（原布局 → 地形） | 22 → 25 | 3 → **2** | 5 → **4** | 22 → 22 |
| E/连接（P4 实测） | | | | 260 → **155** |
| 导线穿本体 | 2 | 2 | 1 | **0** |

⚠ **交叉数基本没变**（52 → 53）—— 这正符合「交叉是网表拓扑的原生属性」的判断。
  值在于：**这是一套不需要人手写任何坐标的通用机制**，
  而之前四页里有三页靠的是我手写的坐标。

⚠ 几何观感略有退步（符号占位穿越 4 → 11 处，P3 占 6 处），还需要收。

## ★ 后优化：目标函数必须是**真实布线结果**，不是直线距离

> 「布局是对的，从网络连接看它很顺。问题是连线引起的 —— R17 穿过了 C13/C14，
>   其实只要左移到空白区、再水平摆一下就很顺。能否在后优化阶段发现并调整？」
> —— 用户 2026-09-29

**能，而且这暴露了降能量那一步的根本局限**：它的 E 用的是**引脚间直线距离**，
**看不见「这根线得绕过 C13/C14」**。所以优化器认为那个位置很好，实际布出来很丑。

→ 后优化换一个目标：**离线跑一遍布线再评分**。

```
分数 = 400 × 穿元件本体次数  +  60 × 异网交叉次数  +  1 × 总线长
动作 = 每个器件试 {8 方向 × 3 步长} 和 {8 种姿态}，轻的先调
接受 = 分数变低 **且** 不新增占位冲突（骨架是对的，不许推翻）
```

⚠ **可行性检查必须查全账本（含符号位）。** 只查本体的话，后优化会把器件越拉越近
  去缩短线长，结果符号没地方放 —— 实测 P2 的符号占位穿越 1 → **7**。

|---|---|---|
| P1 | 3 / 27 / 10350 | **1 / 9 / 6605** |

| P3 | 1 / 1 / 2425 | **0 / 0 / 1625** |

落地后的真实数字（四页网表全绿）：

|---|---|---|---|

**交叉 52 → 40（降 23%），穿本体 5 → 2**，而且**全程没有一个人手写的坐标**。

⚠ 符号占位穿越没改善（11 处）—— 离线评分里**没有符号**这一项，
  它只算导线和本体。这是下一个要补的。

## ⚠ 只连电源/地的器件**根本不在信号图里**

它们的质量是 0 —— 不在 `refs` 里，**地形布局从头到尾没摆过它们**，
一直停在很早以前的坐标上，有的已经在图框外。
实测 daikin-rcu P2：21 个器件**只落地 14 个**，C10/C11/C12 停在 x=50（框外）。
用户的报告是「P2 没有连线」—— 其实线一直在，是那一片器件脱节了。

→ 规矩和 PCB 那边一样：**贴着它所服务的器件**（共享电源网、质量最大的那个），
  按宿主本体外沿分环排开；数量多就往外再开一环。

⚠ **别给它们加「到宿主的弹簧」让它们进入能量优化。**
  实测 P2 的 10 个去耦电容宿主全是 U2，弹簧把它们一齐拽向 U2，
  E 从 75 涨到 122、占位冲突 15 → 17，**更糟**。
  「贴宿主」只用来定**初值**，之后交给外扩和后优化。

## ⚠ 离线布线模型必须和真实画法一致

要挂符号的网（电源地、跨页端口、跨盆地），实际是**两端各放一个符号**，
不是一根跨页长线。按长线建模，离线算出来的交叉和实际对不上，
优化器就看不见真正的问题。→ 这类网按**短支线**建模。

⚠ 但这样又会**低估**：改完 P4 离线报 0 交叉、实际 17。
  离线模型的用处是**比较两个候选**，不是预测绝对值 —— 别拿它当验收。
